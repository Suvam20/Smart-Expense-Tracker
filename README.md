## ✨ Features

- 📊 **Dashboard** — Overview of income, expenses and balance
- 📈 **Bar Chart** — Monthly expense visualization for full year
- 🍩 **Donut Chart** — Category wise spending breakdown
- 💳 **Summary Cards** — Total balance, income and expense cards
- 📋 **Transaction List** — Search and filter all transactions
- 🔍 **Search** — Search by description and category
- 📅 **Date Filter** — Filter transactions by date
- ➕ **Add Transaction** — Add income or expense with category
- 📉 **Analytics Page** — Savings rate, avg daily spend, category progress bars
- 💾 **LocalStorage** — Data persists after page refresh
